# Joint health monitor - explanation

**Safety thresholds.** I used three fixed limits: torque 180 Nm, temperature 105 C and vibration 11.2 mm/s. The shoulder normally runs around 110 Nm, so 180 is well above anything a normal payload produces but still below what the motor can damage itself at. 105 C is roughly where grease and seals start to suffer. 11.2 mm/s is the "unacceptable" zone I took from the ISO 10816 vibration charts. The check is a plain loop of if-statements in `hard_stop()` and it runs before the model is even trained, so if scikit-learn is missing or the model is wrong the arm still stops. A missing/NaN reading is also treated as a stop.

**Combining model and log.** A k-nearest-neighbours model (written by hand, k = 7, values scaled first) compares the 9 sensor values with the past readings and gives a wear probability: the share of the 7 closest past readings that were worn. The log scanner reads only the last 14 days of notes for that arm, adds up weighted keywords (e.g. "grinding" = 3, "noise" = 1) and ignores a keyword if "no/not/fine/normal..." appears in the 3 words before it. The score is capped at 1. If both are worried (prob >= 0.6 and log >= 0.5) the result is SCHEDULE_MAINTENANCE; if only one is worried it is MONITOR; if neither it is SAFE. A probability of 0.85+ alone is also enough for SCHEDULE_MAINTENANCE. EMERGENCY_STOP only comes from the hard limits or the spoof check.

**Spoofed sensor defense.** All three joints carry the same payload, so their torques should rise and fall together. For each joint I divide torque by its normal value and compare it with the average of the other two joints. If the gap is more than 0.35 the torque is flagged as untrusted and the arm is stopped, since we cannot prove it is safe. It would catch someone faking a single joint's torque to a low number (my test: shoulder shown as 45 Nm while it is really hot and shaky). It would NOT catch an attacker who changes all three torques consistently, or one who makes a small change inside the 0.35 gap. It can also false-alarm on a real single-joint collision.
